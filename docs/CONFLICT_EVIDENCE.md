# Реальный конфликт README

Работа индивидуальная; две роли моделируются двумя feature-ветками одного автора.

Команда:
```text
git merge origin/develop
```

Результат Git:
```text
Auto-merging README.md
CONFLICT (content): Merge conflict in README.md
Automatic merge failed; fix conflicts and then commit the result.
```

Содержимое конфликтующего участка:
```text
# Hobby Shop — лабораторная работа 3

<<<<<<< HEAD
Учебный интернет-магазин товаров для хобби и творчества с корзиной.
=======
Учебный интернет-магазин товаров для хобби и творчества с каталогом.
>>>>>>> origin/develop

Вариант 1. Работа выполняется индивидуально: роли тимлида, разработчиков,
тестировщика и технического писателя совмещены одним участником.
Разработка ведётся в ветках main, develop и feature/*.
```

Решение: объединены оба дополнения, итоговая строка описывает каталог и корзину. Маркеры конфликта удалены. После этого создан merge-коммит в feature/readme-cart и Pull Request в develop.

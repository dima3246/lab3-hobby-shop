# Хобби — учебный магазин

Учебный интернет-магазин товаров для хобби и творчества с каталогом и корзиной.

Вариант 1 лабораторной работы 3. Работа индивидуальная: все роли совмещает dima3246.

## Возможности

Каталог из шести демонстрационных товаров, поиск, категории, корзина с ограничением остатков, расчёт суммы и учебное оформление заказа. Корзина сохраняется в браузере. Реальная оплата, доставка и личный кабинет не реализованы; стек полноценного магазина обоснован отдельно в отчёте.

## Запуск

Требуется Node.js 20 или новее. Установка пакетов не нужна.

```text
npm start
```

Открыть http://127.0.0.1:8080/. Проверки: `npm test`.

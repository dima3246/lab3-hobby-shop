# Hobby Shop — лабораторная работа 3

Учебный интернет-магазин товаров для хобби и творчества с каталогом и корзиной.

Вариант 1. Работа выполняется индивидуально: роли тимлида, разработчиков,
тестировщика и технического писателя совмещены одним участником.
Разработка ведётся в ветках main, develop и feature/*.
